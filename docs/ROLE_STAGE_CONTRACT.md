# 角色执行与跨库阶段发布合同

本模块是整图 actor 驱动的生产接入层；显式 Python fixture 与 pinned Codex 的本机固定响应 RPC 都属于诊断。native descriptor 只允许 fixed_role_packet_template，实际 frozen packet 到达后绑定结果，不能选择真实模型/provider 或任意执行代码。formal proof、shadow 挑战/发现质量及真实 solver/grade 全图仍需独立验收。两种 transport 复用 CanonicalCards、DerivedStage、Registry、CorpusStore 与 StageJournal 的提交与跨库发布，不能把模拟计数伪装为真实调用。

native 执行前固定 CLI hash、源/记忆服务、预算、模板 final 和 exact StageInputs；实际 profile 明确拒读 controller parent、scope/output 根，绝对 wall 期限不超过阶段预算。所有 stdio/provider/披露 bytes 用 RPCAdmission 原子接入，同一角色原始流与结果不转写成 exec JSONL。sealed 后 crash 重交原结果；退出未 sealed 只提交 interrupted raw/audit，缺句柄/仍运行保持 started。主库提交复用原出版流程，shadow child receipt 在 parent publication 前不进入后继输入。cache/resolve 重验 native raw 与 exact child receipt，不只检查 DB 中 receipt 存在。

开始固定 stage input、budget、fixture code 或 native descriptor、store binding 和 attempt；对应执行 profile 拒读 controller 账本父目录、scope 根与输出根，过滤环境，禁止外网。extractor/derived 来源通过固定 packet 重建 immutable reader，research 只展开确切冻结 projection。packet 不含控制路径、评分答案或其他臂资料。禁用/无 eligible 阶段不运行 actor，无 eligible 的空 batch 走确定性 typed API。

结束封存 bounded 原始文件 hash、source audit、memory audit；重新播放 transport 和全部读取，核对确切命令与 input。raw/materialization、公开 research 输出、实际 auto_load/open（不推定行为贡献）、extractor corpus snapshot、stage finish 与主 receipt 一起提交。拒绝材料、失败原始流与未知 transport usage 仍保留。缺句柄/仍运行不能标结束；退出未封存保留 interruption，不重发。

未封存 interruption 也保留已有 bounded source/memory audit 原始字节与 hash，明确标为未校验资料；它不能据此创建 card、usage 或提案。缺失 audit 不伪造空披露证明。

shadow store 只由 StageInputs 的实际 fork 打开，不能信任调用者指定路径。child 完成独立原子提交；父发布绑定 input、fork identity、child attempt/completion/capture 与结果 hash。父发布前不提供给后继阶段，父提交 crash 后复用同一 child receipt。parent ledger 永不导入 shadow canonical/proposal/usage。母本已形成的 proposal 或失败反馈不进入这次 shadow 的预提案 corpus。父完成记录和任意恢复必须重新核验原 child receipt，不能用文件存在或手写 success 布尔值证明质量。

本协议的 outcome 只表示 transport/materialization 是否完成；accepted proposal 不等于更有效方案，source provenance 不等于语义真，shadow 结构完成不等于更高 research productivity。真正质量 verifier 和正式晋升不由本模块授予。
